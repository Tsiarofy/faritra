## Faritra

Faritra est un jeu inspiré de Go, avec les mêmes règles que celui-ci, avec un style personnalisé

## Développement

### Prérequis

- Node.js dans une version compatible avec Expo SDK 54
- npm

### Installation et lancement

```bash
git clone https://github.com/Tsiarofy/faritra.git
cd fanorona
npm ci
npm start
```

Le serveur de développement Expo démarre. Suivez les instructions affichées dans le terminal pour ouvrir l’application sur un appareil ou un simulateur.

Vous pouvez aussi lancer directement une cible :

```bash
npm run android  # Android
npm run ios      # iOS (macOS et Xcode requis)
npm run web      # Navigateur web
```

Pour vérifier le code avec ESLint :

```bash
npm run lint
```
